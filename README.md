# Задание 2  
Созданы модели:  

### Модель пользователя (`users`)  
- Наследуется от `AbstractUser`.  
- Авторизация по email (замена стандартной).  
- Дополнительные поля: телефон, город, аватарка.  

### Модели курса и урока (`lms`)  
**Курс:**  
- Название  
- Превью (изображение)  
- Описание  

**Урок:**  
- Название  
- Описание  
- Превью (изображение)  
- Ссылка на видео  
- Связь с курсом (один курс — много уроков)  

### Требования:  
- Модель пользователя размещена в приложении `users`.  
- Модели курса и урока — в отдельном приложении.
